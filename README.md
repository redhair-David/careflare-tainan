# Careflare / Zhaoyao Day

Single-page site for a Taiwan caregiver gathering.

- Date: 2026-12-12
- Place: ICC Tainan (Gueiren)
- Orders: the RSVP builds a demand note and opens the official LINE account. Phone numbers stay on the note. They are not stored in a public database.

## LINE

1. Put the official account basic ID in the host panel, for example `@careflare`.
2. Guests tap the button that opens `https://line.me/R/oaMessage/` with the note already filled in.
3. The note arrives in LINE Official Account. Open the LINE Official Account app on your phone to read it.
4. Share the published site URL plus `?oa=yourid` (ASCII only, no @ required in the query).
